# 追加仕様

`docs/design.md`は実装済みの内容(ファイル名や、どのように実装したか)を記述する。このファイルには、今後追加していく外部仕様(何を実現したいか)を追記していく。実装が完了したら、該当項目を`docs/design.md`に反映したうえで、この一覧から削除する。

## 雛形

新しい項目を追記するときは、この形式に合わせる(「未決定事項」は無ければ省略してよい)。

```markdown
## <機能名>

**状態:** 未定 / 検討中 / 確定(実装待ち)

**仕様:**
<実現したいことを記述>

**未決定事項:**
- <まだ決まっていない点があれば列挙>
```

## オーディオ: `WAVEFORM_BUFFER`への波形書き込み

**状態:** 未定

**仕様:**
`firmware/src/audio.rs`はCORE1上でI2S出力(PIO2 + DMA_CH3、MAX98357A宛)を常時行っており、256サンプルの共有バッファ`WAVEFORM_BUFFER`の内容を無限ループで読み出してDMA出力し続けている。このバッファへ実際の波形サンプルを書き込む仕様は、まだ提示されていない。
